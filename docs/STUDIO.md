# الاستوديو الرياضي

بورتال إيزي كوتش بهوية كحلية وزرقاء: تنقل جانبي ثابت للكمبيوتر وقائمة جانبية قابلة للإغلاق للجوال، بحث عن المتدربين، وبطاقات ملخصات ومتابعات وجاهزية البرامج والتحصيل الشهري والنشر الأسبوعي. تظهر قائمة المتدربين كبطاقات على الجوال. تنبيه الوزن يخص من حُدد له وزن مستهدف، وليس جميع المتدربين. التجديد المجدول والتجميد يؤخذان في الاعتبار، والتواريخ بتوقيت الرياض.

## بناء البرنامج

مكتبة 876 حركة بأيقونات SVG توضيحية بدل الصور الفعلية. تتوفر أسماء وتعليمات عربية لكل الحركات، والبحث عربي أو بالاسم الإنجليزي مع فلاتر العضلة والمعدة والمستوى. يظهر شرح الأداء بالعربية في تفاصيل المكتبة ومحرر البرنامج وبوابة المتدرب، مع بقاء توجيهات المدرب المخصصة مستقلة. المكتبة لا تدّعي حصر كل حركة عالميًا، ويمكن إضافة حركة مخصصة. [مصدر البيانات والترخيص](EXERCISE-SOURCES.md).

الحصة تحتوي أيامًا وحركات وجولات وتكرارات وراحة، مع إعادة ترتيب ونسخ الأيام. اختيار أول حركة يستبدل صف البداية الافتراضي. حفظ تلقائي ومسودات مستقلة، ثم نشر على رابط العميل نفسه.

ارفع فيديو من الجهاز أو افتح QR من داخل الحركة: من الجوال اختر الفيديو، وسيظهر في الحركة على الكمبيوتر. QR صالح 15 دقيقة لفيديو واحد. الأنواع MP4 / MOV / WebM حتى 50MB. الرفع المباشر إلى Supabase Storage يتجنب حد ملفات Vercel. تُفحص الصيغة والحجم، والحاوية خاصة، وروابط التشغيل مؤقتة لدقيقتين. تسجيل بيانات العملاء يمر عبر RLS؛ المفتاح الإداري يستخدم فقط لتوقيع مسار فيديو سبق التحقق من صلاحية الوصول إليه.

معرّفات ثابتة للصفوف تمنع إرفاق الفيديو بحركة أخرى عند إعادة الترتيب أثناء الرفع. إعادة فتح QR تتيح إعادة المحاولة، والملف الواحد لا يُستبدل بملف آخر. توجد حدود 100 حجز فيديو في اليوم للمدرب. الملفات المعلقة لا تُعرض للعميل؛ إدارة تنظيف الفيديوهات غير المستخدمة ومدد الاحتفاظ ما زالت تحتاج سياسة قبل استقبال محتوى حقيقي.

## التغذية والتقدم

أهداف سعرات وبروتين وكارب ودهون، ووجبات اختيارية بالاسم والوقت والمكونات والكميات والبدائل والقيم الغذائية. يظهر مجموع الوجبات والفرق عن الهدف، ولا تُستبدل الأهداف إلا بزر صريح. قيم الطعام يحددها المدرب؛ لا قاعدة أغذية أو توصيات آلية.

هدف مرحلة ووزن مستهدف اختياري، وملاحظات خاصة للمدرب محجوبة حتى عن API المتدرب. تسجيل وزن اختياري مع سجل واحد لكل يوم، وتصحيح وحذف، ومنحنى آخر 30 تسجيلًا ومتوسط آخر 7 تسجيلات. يُمنع المستقبل وما قبل سنة. حذف العميل يزيل أوزانه وأهدافه ويوقف روابطه. لا صور جسم أو بيانات طبية أو سجل أداء تمرين يومي.

## رابط العميل

من ملف المتدرب اضغط «تفعيل رابط العميل». احفظ الرابط ورمز الدخول المكون من 6 أرقام عند الإنشاء؛ لا يعرضان مرة ثانية. شارك الرمز منفصلًا عن الرابط. الصلاحية 180 يومًا، ويمكن الإيقاف أو التغيير؛ تغيير الإيميل يلغي الرابط. حماية عشر محاولات في 15 دقيقة تشمل الوصول إلى الفيديو. المتدرب يرى آخر برنامج منشور، وجباته ووزنه، دون إيميل أو دفعات أو ملاحظات المدرب. التحديث تلقائي كل دقيقة ما دامت الصفحة ظاهرة، أو بزر التحديث. الإلغاء يقفل الصفحة في أول تحديث ويمنع توقيع فيديو جديد؛ رابط الفيديو الموقّع سابقًا قد يبقى صالحًا حتى دقيقتين.

النسخة الحالية محمية بـVercel Authentication. فتح رابط العميل أو QR من جهاز آخر يتطلب حساب Vercel المسموح أثناء المراجعة. لا نفتحها للعامة تلقائيًا.

## التحقق

```bash
npm test
npm run lint
npm run typecheck
npm run build
# مع تشغيل المعاينة المحلية
node scripts/studio-browser-check.mjs
```

نجح 33 اختبارًا، بما فيها RLS والوجبات والوزن اليومي وتصحيحاته ورفض التاريخ المستقبلي والرمز الفارغ وإلغاء الروابط وعزل الفيديو والملاحظات. نجح اختبار المتصفح برفع فيديو WebM اصطناعي من الجهاز ومن QR، ونشر وجبات، وفتح رابط برمز وتسجيل وزن وتصحيحه، ومنع مشاهدة الفيديو دون تصريح، وفحص العرض على الجوال. النتائج والصور محليًا في `artifacts/studio`.

`scripts/studio-remote-check.mjs` فحص Supabase الفعلي والحاوية الخاصة ومنع مدرب آخر من توقيع الفيديو ورفع QR ونشر الوجبات والرابط والوزن وإلغاء الوصول. يحتاج ملفات الاختبار الخاصة المتجاهلة داخل `.vercel`؛ لا ترسلها للمستودع. لا رسائل أو بيانات أشخاص حقيقيين في الاختبارات. فحص Advisors أبقى تحذير إعداد منع كلمات المرور المسرّبة الموجود سابقًا فقط.
