# قائمة تدقيق EasyCoach

تاريخ المراجعة: 2026-11-11. النطاق: مستودع EasyCoach الحالي، بما فيه تغييرات محلية سابقة غير ملتزم بها. ليست هذه شهادة أمان أو إعلان جاهزية للإنتاج.

## المنهج وحدود الدليل

- **اجتاز**: تحقق عملي محدد، أو فحص ساكن آلي مذكور صراحة؛ لا يُعمّم على بقية النظام.
- **فشل**: عيب مؤكد في السلوك أو الكود؛ يوضح الجدول إن أُصلح وما يزال مطلوبًا.
- **لم يُختبر**: لا توجد نتيجة تنفيذ كافية، حتى لو بدا الكود صحيحًا.
- **لا ينطبق**: الوظيفة غير موجودة ضمن المنتج أو أُلغي طلبها.
- الشدة: **حرجة / عالية / متوسطة / منخفضة / —**. الشدة تخص أثر المشكلة، وليست نتيجة فحص.
- «عملي محلي» هنا يشمل PostgreSQL مضمّنًا حقيقيًا عبر PGlite، وحسابات اصطناعية، ومعالجة ملفات حقيقية. الاختبارات ذات محولات Storage/الشبكة البديلة مُسمّاة كذلك؛ لا تثبت سلامة الخدمة المستضافة.
- لم تُنفّذ في هذه المراجعة عمليات حذف أو اختبارات هجومية أو ترحيلات على الإنتاج، ولم تُرسل رسائل خارجية. لا تُنسخ الأسرار أو صور المتدربين إلى هذا التقرير.
- توجد تعديلات سابقة في الدعم والاستيراد والأتمتة وغيرها؛ لم تُضمَّن كاملة إلى الإصلاحات تلقائيًا. مراجعة ملف غير متتبع لا تعني أنه منشور.

## 1. جرد الميزات والمسارات أولًا

الجرد مستخرج من `app/**/page.tsx` و`app/**/route.ts` وملفات الإجراءات والخدمات، وليس من وصف المنتج وحده.

| المسار أو المدخل | الوظيفة الموجودة فعليًا | التخزين/الاعتماد |
|---|---|---|
| `/` | تحويل للوحة المدرب | جلسة المستخدم |
| `/login`، `app/actions.ts` | كلمة مرور، تسجيل حساب، رابط دخول بالبريد | Supabase Auth أو Auth محلي |

| `/auth/callback`، `/logout` | تبادل رمز التحقق؛ POST للخروج وGET بلا تغيير جلسة | Auth/cookies |
| `/coach`، `/coach/today` | متابعة المتدربين والمهام والتنبيهات المحسوبة | snapshot/RLS |
| `/coach/clients` | بحث وقائمة ولوحة متدربين | clients/سجلات الاشتراك والتقدم |
| `/coach/clients/[id]` و`/edit` | ملخص، برنامج، تغذية، مالية، بيانات ودعوة، تقدم وتتبع | ملكية coach→client |
| `/coach/library` | دليل تمارين، تمارين خاصة، قوالب وإسناد ونسخ وأرشفة | templates/programs/media |
| `/coach/finance` | اشتراكات وتجديد وتجميد ودفعات وعكس دفعة | دفتر مالي يدوي؛ ليست بوابة دفع |
| `/coach/settings` | اسم الحساب، اسم وصورة المدرب، تفضيلات، روابط انضمام وتصدير وتنظيف صور | profiles/branding/preferences |
| `/coach/support` | صندوق دعم للمالك فقط، في التعديلات المحلية السابقة | support_tickets؛ الميزة غير متتبعة بالكامل |
| `/me` | سجل المتدرب المرتبط، برنامج وتغذية ووزن وتحديثات | حساب موثّق وربط trainee_user_id |
| `/p/[token]` | بوابة دون حساب، لكن مع PIN منفصل وجلسة؛ وزن وصور وسجلات | portal_links/proof/RLS RPC |
| `/invite/[token]` | ربط حساب موجود/جديد بنفس البريد الموثق | دعوة 7 أيام أحادية الاستخدام |
| `/join/[token]` | طلب انضمام يحتاج مراجعة المدرب | join_links/requests؛ لا يمنح وصولًا |
| `/upload/[token]` | رفع فيديو من الهاتف عبر رابط محدود | upload_sessions/coach-videos |
| `/privacy` | إشعار خصوصية ما يزال مسودة | معلومات المشغّل غير مكتملة |
| `POST /api/import` | قراءة CSV/XLSX ومعاينة وربط أعمدة قبل التطبيق | parser وحدود حجم + إجراءات استيراد |
| `GET /api/export` | JSON أو CSV متدربين أو مصنف كامل | snapshot خاص بالمتصل |
| `/api/media/[id]`، `/api/exercise-media/[id]` | فيديو خاص/رسم تمرين بعد تفويض؛ range محلي أو signed URL | coach-videos/exercise-illustrations |
| `PUT /api/local-upload/[id]` | استقبال فيديو محلي محدود | ملفات محلية للمعاينة |
| `/api/progress-photos/[id]` | قراءة صور خاصة وPUT محلي؛ الرفع المستضاف عبر توقيع | progress-photos/تفويض العميل أو المدرب |
| `GET /api/coach-avatar/[id]` | صورة هوية المدرب القابلة للمشاركة عمدًا | ليست صورة جسم خاصة |
| `/api/support/tickets`، `/[id]`، `/api/support/attachments/[id]` | بلاغات واقتراحات وحالة ومرفق | تعديلات محلية سابقة، owner server check |
| `app/*-actions.ts` | أوامر خادمية للحفظ والنشر والدعوات والصور والاستيراد والتفضيلات | تحقق Zod + PostgreSQL RPC |
| `automation/` | أدوات تطوير محلية: queue وn8n وTelegram ومراجعات وتشغيل CLI | خارج تطبيق المتدرب، غير متتبعة سابقًا؛ ليست مراسلات تدريب تلقائية |

إعداد النطاقات الفرعية **غير منفّذ** وقد ألغاه المستخدم؛ لا توجد مطالبة بملكية `easycoach.app` أو بتفعيل DNS/SSL.

- ترحيل edit_revision جديد ومتوافق بالإضافة: اختُبر من قاعدة فارغة ومحليًا بالمتصفح؛ **لم يُطبّق على الإنتاج**. يلزم تطبيقه على staging ثم مراجعة rollout قبل اعتبار حماية التعارض فعالة هناك. لم تُعدّل ترحيلات مطبقة.
- configure-host يستخدم production فقط افتراضيًا. لبيئة أخرى يلزم EASYCOACH_HOST_TARGET وEASYCOACH_HOST_ENV_FILE لملف خاص منفصل؛ يرفض نفس مشروع Supabase أو نفس APP_URL للإنتاج. لم تُشغّل الأداة ولم تُغيّر متغيرات مستضافة.
- أُضيف no-referrer/noindex لصفحة QR upload، ومفتاح React مستقل لكل token حتى لا تُعاد حالة بوابة قديمة عند التنقل بين رابطين؛ لم يُدعَ تنفيذ تبادل token يحذفه من URL.
- ظهرت في سجل Next dev المحلي أسماء مدخلات اصطناعية لإجراءات الخادم؛ لذلك لا يُستخدم الخادم التطويري مع بيانات حساسة حقيقية. سجل الإنتاج وتنقيحه لم يُفحصا.
