# مصدر مكتبة الحركات

[free-exercise-db](https://github.com/yuhonas/free-exercise-db) بواسطة yuhonas، 876 حركة في النسخة المضمنة بتاريخ 7 نوفمبر 2026. [الترخيص](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md): Unlicense / Public Domain. نسخة الترخيص في `lib/exercise-data/EXERCISE-LICENSE.txt`.

البيانات في `lib/exercise-data/exercises.json`. حُولت صورتا كل حركة إلى WebP محلي 360×180، الصورتان بجانب بعضهما، بحجم إجمالي يقارب 5MB. لا اتصال بالمصدر أثناء تشغيل المكتبة ولا مزامنة أو تحديث تلقائي. الأسماء الأصلية والعضلات والمعدات والمستوى والتعليمات الإنجليزية محفوظة. أُضيفت أسماء عربية للحركات الشائعة ومرادفات بحث عربية؛ بقية الحركات تعرض اسمها العالمي.

المكتبة مرجع بصري يختار منه المدرب، وليست تقييمًا طبيًا أو اختيارًا آليًا للتمارين.
