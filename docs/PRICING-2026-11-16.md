# Public pricing landing — 2026-11-16

The free-mode `/pricing` route previously returned HTTP 307 to `/` in both the proxy and the page. It now returns HTTP 200 with a standalone Arabic RTL free plan, a limited-time badge, current price of 0 SAR, feature summary and one primary signup link. Paid-mode pricing remains available when billing is enabled.

The signup link opens `/login?register=1`. It preserves incoming query values, including all UTM fields, `ttclid`, repeated keys, empty values and encoded Arabic text. `register` is deliberately forced to `1` so an incoming value cannot change the CTA to sign-in mode. The free page does not query account or paid-plan data.

The existing TikTok initialization queues one initial PageView. Pricing additionally queues ViewContent, deduplicated across React effects and script callbacks and emitted again after returning from another route. Its properties contain only a fixed pricing content identifier; no query values are copied into event properties. Registration and payment conversion behavior is unchanged.

## Validation

- Production build, TypeScript and ESLint passed; browser bundle secret scan passed.
- 24 focused tests across pricing, TikTok pixel/events/attribution, site metadata and free-platform behavior passed.
- `npm run test:pricing` passed six production-browser scenarios: iPhone 13 WebKit, Pixel 7 Chromium and desktop Chromium, each in light and dark themes.
- Each scenario verified HTTP 200 without redirect, Arabic RTL layout, no horizontal overflow, one accessible signup CTA, all incoming query values reaching the actual registration form, PageView/ViewContent queue calls and back navigation. No signup was submitted.
- Desktop axe checks found no WCAG A/AA violations. Browser scenarios reported no uncaught page errors.
- Screenshots and machine-readable results are generated locally under `artifacts/pricing/`.

Browser checks use device emulation, not physical iOS/Android devices. Service workers are blocked to isolate navigation and pixel assertions. TikTok network calls are intercepted; tests verify the official queue calls without polluting campaign data. TikTok Events Manager receipt requires a separate live check.
