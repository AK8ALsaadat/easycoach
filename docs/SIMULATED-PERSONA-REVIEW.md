# مراجعة الشخصيات المحاكية — EasyCoach

هذه **مراجعة منتج محاكية** وليست بحثًا ميدانيًا أو مقابلات مع مدربين/متدربين. راجعنا مسارات العمل قبل التنفيذ، ثم راجعنا الحل البرمجي بعد التنفيذ وربطنا الثغرات بقبول يمكن اختباره.

| الشخصية | السيناريو ومعيار القبول | ملاحظة ما قبل التنفيذ | نتيجة المراجعة بعد التنفيذ |
|---|---|---|---|
| مدرب مستقل، قائمة صغيرة | فتح سجل عميل وإضافة قياس؛ لا يختلط سجل عميل آخر | الصور غير مهيكلة حسب الزاوية | تبويب العميل والتسجيل المنسوب + صور Front/Back/Side |
| مدرب مزدحم، قائمة كبيرة | تمييز المتأخرين وفتح سجلهم مباشرة | لا تكرار مستقل للقياسات والصور | cadence منفصل وتنبيهات لكل عميل |
| مدرب قوة وتضخم | مقارنة نفس الزاوية وتاريخ القياسات | الصورة تحتاج اتجاهًا واضحًا | ثلاث زوايا مسماة ومقارنة بين تاريخين |
| مدرب خسارة وزن | عرض القيم والتواريخ دون حكم إيجابي/سلبي | صفحة اليوم لا تلخص آخر وزن | ملخص اليوم يعرض الوزن وتاريخه فقط |
| مدرب مبتدئين | العميل يجد المطلوب دون مصطلحات تقنية | سجل التمارين يفتقد مدخلًا سريعًا | CTA للوزن/التحديث وتفاصيل الوصفة باقية |
| مدرب تغذية | الاطلاع على الماكروز المسندة فعليًا | لا ينبغي اختراع خطة خارج نموذج المشروع | عرض الخطة الفعلية من البرنامج |
| مدرب عن بعد | يرى التحديثات بعد حفظها من مكان آخر | كان الاعتماد على تحديث دوري | تحديث صريح ودوري قائم في البوابة |
| مدرب جوال | تحميل صور كبيرة دون تعطل | صور الكاميرا الثقيلة | تحويل/ضغط محلي وإعادة المحاولة |
| مدرب سطح مكتب | مقارنة تاريخين ومراجعة القائمة | الصور بلا workflow موحد | لوحة مقارنة وتبويبات السجل |
| مدرب يستورد بيانات | استمرار التاريخ القديم دون قلبه لسجل جديد | الاستيراد لا يتضمن صورًا | قالب موثق؛ تاريخ القياس لا يُعامل كآخر تحديث دوري |
| مدرب يراعي الخصوصية | موافقة صريحة قبل رفع الصورة | الموافقة كانت غائبة عن المسار | موافقة موثقة وفحص ارتباط الصورة بالسجل |
| مدرب يراجع أشهرًا من التقدم | منحنى وزن وقراءة تواريخ وقياسات | المقارنة غير منظمة | مخطط اتجاه ومقارنة؛ اختبار الفروق والحقول الناقصة عبر PostgreSQL والمتصفح المحلي |
| مدرب لتحديثات ناقصة/متأخرة | الوزن وحده لا يوقف إنذار القياسات | تنبيه واحد لا يعكس أنواع البيانات | تنبيهات مستقلة؛ الوزن التاريخي لا يعد تحديثًا قياسيًا |
| مدرب عربي RTL | واجهة عربية قابلة للتنقل | نصوص تحتاج وضوحًا عند إضافة الجدول | حقول مسماة، وأخطاء عربية وقائمة إجراءات عائمة مجرّبة بالمتصفح |
| مدرب يصور في الجلسة | تسجيل باسم المدرب وموافقة العميل | نسبة الصورة غير واضحة | رفع من جهة المدرب مع إقرار الموافقة |
| مبتدئ لا يعرف المصطلحات | تسجيل الوزن من أول شاشة | المسار طويل | CTA مباشر للوزن والتحديث |
| رافع أوزان خبير | يرى المجموعات/العدات المنفذة منفصلة عن الوصفة | يوم البرنامج يعرض كل الأيام دفعة واحدة | تنقل يومي؛ سجل أداء موجود |
| متدرب خسارة وزن | يرى الوزن بوحدة وتاريخ دون وصمة | لا ملخص لآخر إدخال | الوزن بوحدة كجم وتاريخه |
| متدرب بناء عضل | يرى التغذية والتمارين المنشورة | الماكروز قد تكون فارغة | عرض الأهداف المعينة مع empty state |
| مشغول يريد تحديثًا سريعًا | تسجيل الوزن بأقل خطوات | تحديث كامل قد يكون مرهقًا | زر تسجيل الوزن مستقل عن الصور |
| يستخدم الرابط بلا حساب | فتح بوابته فقط | مسار PIN القديم يضيف خطوة دخول | الرابط الشخصي الحديث يستبدل سرًا عشوائيًا بجلسة خادمية، دون حساب أو PIN؛ يبقى المسار القديم متوافقًا |
| ينشئ حسابًا لاحقًا | استمرار سجل المتدرب بعد ربط موثوق | يجب عدم المطابقة بالاسم | مسار الدعوة/الربط القائم يعتمد رمزًا موثوقًا |
| يتنقل بين أجهزة | يرى السجلات المحفوظة على الخادم | التخزين المحلي ليس مصدر الحقيقة | RPC خادمي + تحديث snapshot |
| هاتف قديم | الاستخدام لا يعتمد على معالجة ضخمة | الصور الثقيلة تعيق الجهاز | ضغط بحد للأبعاد وصور مصغرة؛ فحص متصفح بعرض صغير، دون ادعاء اختبار جهاز قديم فعلي |
| اتصال بطيء | الخطأ لا يدعي نجاح الحفظ | انقطاع الرفع قد يترك حالة مجهولة | حالات الخطأ وإعادة المحاولة، مفاتيح رفع ثابتة |
| حساس للخصوصية | الصور لا تكون روابط عامة | يجب تقييد الوصول المباشر | صلاحية الوصول والتحقق من المالك بالـRPC؛ اختبارات أذونات قائمة |
| يسجل الوزن فقط | لا يُطلب منه القياس أو الصور كل يوم | تنبيه القياس قد يتأثر بالوزن | الاختبار يثبت أن الوزن التاريخي لا يحدّث القياس وأن pending لا يحدث الصور |
| يحتاج تصحيح إدخال خاطئ | يمكنه تصحيح اليوم دون مضاعفة عند الإعادة | إعادة المحاولة قد تكرر الصور | رفع ثابت المعرف وupsert والحذف المصرح |
| عربي يحتاج RTL | التواريخ والأزرار واضحة بالعربية | شاشة اليوم كانت مفقودة | شاشة «اليوم» عربية؛ فحص RTL محلي بالمتصفح في خمسة عروض دون تمرير أفقي |
| صور كبيرة من الجوال | المعاينة/الاستبدال/إزالة قبل الإرسال | الصور تحتاج ضغطًا وإزالة metadata | معاينة، تبديل، ضغط WebP وإزالة metadata |

## معايير الاختبار المضافة

- تكرارات كل عميل مستقلة، ولا يستطيع مدرب ثانٍ تعديل جدول عميل المدرب الأول.
- تاريخ القياس يعتمد على سجل قياس فعلي غير تاريخي؛ الصور المعلقة لا تؤجل موعد الصور.
- الوزن يظل إدخالًا سريعًا مستقلًا عن القياسات والصور.
- البرنامج يعرض يومًا محددًا مع اختيار الأيام، ويشير بوضوح إلى الجدول غير المحدد؛ لا يُفترض يوم راحة عند غياب weekday.

## حالة التحقق

النتائج الآلية ترد في تقرير التسليم. هذه الشخصيات الثلاثون مراجعة محاكية، وليست مقابلات أو اختبارات لمستخدمين حقيقيين.

## جولة الاستكمال — 13 نوفمبر 2026

قبل تعديل التنفيذ، أعيد فحص المسارات الموجودة وفق الشخصيات أعلاه. أثرت النتائج في العمل مباشرة:

| الشخصيات المتأثرة | الفجوة المكتشفة | التحسين والتحقق بعد التنفيذ |
|---|---|---|
| مدرب المبتدئين، مدرب القوة، المتدرب المبتدئ والخبير | تعليمات المدرب غير معروضة؛ الوصف القديم من المكتبة لا يثبت أن المدرب كتبه | حقل مستقل لتوجيهات المدرب، مع حفظ ونشر واختبار SQL؛ الوصف القديم يظل محفوظًا دون عرضه |
| مدرب عربي، متدرب عربي، متدرب مشغول | زر إرسال تحديث قد يترك تبويب الرسائل مفتوحًا؛ يوم الراحة يختفي مع برنامج يوم واحد | الزر يفتح القياسات، ورسالة الراحة واضحة؛ اختبارات عرض وتفاعل |
| مدرب التغذية، مدرب التحديثات المتأخرة، متدرب الوزن فقط | متابعة وزن ثابتة بعد سبعة أيام تخالف الجدول المخصص | تذكيرات الجدول الفعلي فقط، مع اختبار 30 يومًا مقابل التأخر الحقيقي |
| مدرب الهاتف، هاتف قديم، اتصال ضعيف، صور جوال كبيرة | مؤشر الرفع لا يبيّن الزاوية أو تقدم النقل؛ تعديل الصورة أثناء الرفع يربك النتيجة | تقدم نقل لكل زاوية ومرحلة تحقق مستقلة؛ قفل الاستبدال/الإزالة والتاريخ أثناء الرفع؛ إعادة محاولة لا تضاعف السجل |
| مدرب ومتدرب يراعيان الخصوصية، مستخدم الرابط | لا يوجد حد صريح لمحاولات استبدال الرابط؛ سجلات Next التطويرية قد تعرض معاملات الحفظ | حد ذري دائم في القاعدة، 429 مع مهلة، وتعطيل سجلات معاملات التطوير |
| مدرب سطح مكتب، مدرب الجوال، جميع مستخدمي العربية | قائمة الإجراءات تُقص داخل الجدول، وأخطاء المتصفح إنجليزية | قائمة عائمة مع فحص موضعها فعليًا، ورسائل تحقق عربية، وفحص RTL بعروض 360/390/430/768/1440 |
| مدرب الاستيراد، مدرب المراجعة الطويلة، متدرب يصحح إدخالًا | ضرورة حفظ التاريخ مع تحسين المصطلحات والأرقام | هجرات إضافية؛ اختبارات الاستيراد والتصحيح والتعارض والمقارنة، وإصلاح تكرار علامة + في تغير الوزن |

فحص المتصفح الآلي المحلي بعد التنفيذ نجح للموافقة وإلغاء إيقاف الصور، ورسائل الخطأ، وقائمة المؤرشفين، والتنقل، وعدم التمرير الأفقي. تمت معاينة لقطة الجوال الناتجة. الكاميرا الحقيقية واختلاف أجهزة iOS/Android، وتأكيد بريد حقيقي، والتخزين المستضاف لا تغطيها هذه المعاينة المحلية.
